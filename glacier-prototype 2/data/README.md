# Data

Put the data files you downloaded from GLAMOS (https://doi.glamos.ch/index.html) here.

Refer to these files by their exact names in the screen descriptions.

## Datasets needed

| GLAMOS dataset | Used for | Format |
|---|---|---|
| Massbalance (latest release) | Mass (Loss), Melt by Elevation, ELA, glacier list | 4 CSV files: observation period / hydrological year, each glacier-wide and per elevation bin |
| Lengthchange (latest release) | Retreat | CSV |
| Volumechange (latest release) | Total mass | CSV |
| Inventory (SGI 1850, 1931, 1973, 2010, 2016, 2023) | Area, map outlines, location | Shapefile, convert to GeoJSON |
| Ice Thickness (`icethickness.2020.r2020`) | Thickness | ASCII, one file per glacier |

Licence: CC BY 4.0. Citation example: GLAMOS (2025). Swiss Glacier Mass Balance, release 2025, Glacier Monitoring Switzerland, doi:10.18750/massbalance.2025.r2025.
